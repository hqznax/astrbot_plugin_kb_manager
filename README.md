# 知识库管理（astrbot_plugin_kb_manager）

方便在聊天与 WebUI 中管理 AstrBot 知识库文档。

## 功能

### 聊天命令
- 查看知识库列表（名称、文档数、块数、描述）
- 分页查看某个知识库下的文档/文件
- 查看单个文档详情
- 安全删除文档（需二次确认）

### WebUI（v1.1.0+）
- 独立插件页面 `dashboard`
- 查看知识库 / 文档列表、搜索
- **直接编辑正文并保存**
- 删除文档
- 新建纯文本文档

> 说明：AstrBot 原生知识库没有“原地改文档” API。  
> UI 里的「保存修改」= 读取文本块拼接正文 → 用新内容重新上传 → 删除旧文档（重建向量索引）。

## 打开 WebUI

1. 打开 AstrBot WebUI
2. 进入：`插件` → `知识库管理` → `Pages` → `dashboard`
3. 也可聊天发送：`知识库界面`

## 命令

| 命令 | 说明 |
|------|------|
| `知识库列表` | 列出所有知识库 |
| `知识库文件 <知识库名|编号> [页码]` | 查看文档列表 |
| `知识库详情 <知识库名|编号> <文档编号|文档ID|文件名>` | 查看文档详情 |
| `知识库删除文件 <知识库名|编号> <文档编号|文档ID|文件名>` | 发起删除（需确认） |
| `知识库确认删除` | 确认并执行删除 |
| `知识库取消删除` | 取消待确认删除 |
| `知识库界面` | 查看 WebUI 入口说明 |
| `知识库帮助` | 显示帮助 |

## 配置

- `only_admin`：是否仅管理员可用（默认 true）
- `page_size`：聊天列表每页条数（默认 10）
- `delete_confirm_seconds`：聊天删除确认有效秒数（默认 60）

## 安装 / 升级

1. 将本目录放到 `data/plugins/astrbot_plugin_kb_manager`
2. 在 WebUI 插件管理中**重载/重启**插件
3. 聊天发送 `知识库界面`，或打开 Pages → dashboard 测试

## 注意

- 删除的是知识库里的「文档/文件」，不是整个知识库。
- 删除会同步清理向量索引与相关块数据，请谨慎操作。
- 编辑保存后 `doc_id` 会变化（因为是重建文档）。
- 正文由向量文本块拼接还原，复杂格式文件编辑后会按纯文本重新分块。
